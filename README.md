## ✨ Features
* **Time Machine:** Simulate future attendance ("What if I miss next week?").
* **Smart Status:** Instantly see `+5 Leave` (Safe) or `-3 Need` (Critical).
* **Timetable Scanner:** OCR scanning to auto-setup your schedule from an image.
* **Secure:** Data is encrypted using AES-256 (Android KeyStore).
* **Semester Forecast:** Month-by-month breakdown of every class until the semester ends.
